# Queens Hairstyle — design demonstration

A bilingual (English/French) design demonstration by Dalal Technologies for Queens Hairstyle, Montréal, built around founder Dr. Amélie.

This is **not** the live salon website. Pages are marked `noindex` so the demo does not compete with queenshairstyles.com in search results.

## Pages

| File | Page |
|---|---|
| `index.html` | Homepage: opening, her story, thought and hand, gallery, Queens Live, menu, style finder, client reviews, booking |
| `founder.html` | Meet the Founder profile |
| `notes.html` | Internal presentation notes and editorial checklist (not linked from the public navigation once launched) |

## Notes

- Plain HTML, CSS and JavaScript. No build step; Netlify publishes the repository root (`netlify.toml`).
- Queens Live shows clearly labelled **example** content. Owner controls work only in the visitor's browser until her accounts are connected.
- Booking links point to the salon's existing booking pages.
- Logo files are the approved Queens Hairstyle logo package.
